# MADELARME

Сайт видеографа Марии Волковой (ник madelarme, Алматы). Заменяет старый volkova.kz. Дмитрий — разработчик, Мария утверждает. Задача от клиента: смелый дизайн «как у топовых видеографов мира», mobile-first, понятные кейсы, цены, форматы, страница о себе. Админка — после утверждения дизайна.

## Стек

- Next.js 16.4.6 (Turbopack; см. AGENTS.md — перед правкой Next-кода читать `node_modules/next/dist/docs/`), Tailwind v4, Motion, Lenis. pnpm 12, Node 24.
- Контент — `src/content/*.json`, контракт — `src/content/types.ts` (зеркало будущих коллекций админки).
- Медиа — `scripts/media.mjs` по `scripts/media.manifest.json`, результат в `public/media` (лежит в git: сайт собирается на GitHub). Исходники (фильмы с YouTube, оригинал портрета) — в `.cache/sources`, в git не попадают.
- Правила для кода: `docs/BUILD-BRIEF.md`. План и исследование: `docs/plan-v1.html`, `docs/research/`.

## Как запустить

- `pnpm install`, затем dev-сервер из `.claude/launch.json`: `madelarme-dev` (порт 3033), запасной `madelarme-dev-alt` (3034).
- Проверки: `pnpm content:check`, `pnpm media:check`, `pnpm lint`, `pnpm typecheck`.
- Статическая сборка как на сервере: `bash scripts/build-static.sh` → `out/`.
- После правки медиа: `pnpm media --only <имя> --force`, изменения в `public/media` коммитятся.
- Скрины 1440 и 390: помощник `trailer/cdp.mjs` (headless Chrome с эмуляцией; обычный `--window-size=390` рисует минимум 500px).

## Деплой

- Тестовый домен https://madelarme.seoweb.kz (noindex). Репозиторий закрытый: `git@github.com:anagra666/madelarme.git`.
- `git push origin main` → GitHub Actions (`.github/workflows/deploy.yml`: проверки, статическая сборка) → ветка `deploy` с готовой статикой → офисный сервер раз в минуту забирает ее, раскладывает в `www/releases/<время>-<коммит>` и переключает `www/current`, сам проверяет и откатывает.
- Пуш в `main` = выкладка. Недоделанное — в рабочую ветку.
- Подробности, команды отката и установка с нуля: `deploy/office/README.md`.

## Хостинг и доступы (без секретов)

- Офисный сервер, проект в `/srv/server/projects/madelarme` (свой контейнер nginx `madelarme-web-1` за общим Caddy). Заголовки безопасности отдает nginx проекта, источник CSP — `src/lib/security.ts`.
- Вход на сервер только с офисного компьютера, команда и правила — в глобальных правилах («Офисный сервер»). Перед работой читать правила сервера, менять только свое, под общей блокировкой, с записью в журнал.
- Сервер забирает сборку ключом только на чтение. Его публичная часть должна быть добавлена в Deploy keys репозитория; пока ее нет, сборку на сервер приходится доставлять вручную (см. «Текущее состояние»).
- Старый контейнер `turbo5-static-madelarme-1` на сервере не трогать: это точка отката, его убирает координатор сервера.

## Принятые решения

- Концепция «Титры»: типографический индекс, видео по действию, личный голос. Палитра: ink #0E0D0C, paper #F3EEE6, signal #FF4D2E. Шрифты: Sofia Sans Extra Condensed (заголовки), Inter Tight (текст), Roboto Mono (мета).
- Текст не делать тонким и мелким (замечание Дмитрия 13.11.2026): mono 13px/500, mono-sm 12px/500, mono-lg 15px/500, цены clamp(20px, 1.9vw, 30px)/500 цветом milk, описания не меньше 16px на телефоне. Секции по высоте контента, на весь экран только хиро.
- Полные фильмы играют с YouTube (youtube-nocookie) только в плеере; лупы, постеры и кадры нарезаны из скачанных фильмов.
- Факты о работах — только из таблицы Марии и названий на YouTube; неизвестные поля скрыты.
- Тарифы и условия — по ответам Марии от 10–11.11.2026 (час 60 тыс., полдня до 6 ч 200 тыс., день до 12 ч 300 тыс., соцсети от 40 тыс. за ролик, дрон и FPV +100 тыс., без предоплаты, сдача 2 недели).
- Казахской версии нет, английская позже.
- Бюджеты для телефона: хиро-видео до 3–4 МБ, на тач-устройствах играет не больше одного видео, липкая кнопка WhatsApp.

## Следующий шаг

1. Показать Марии сайт с ее портретом и собрать правки.
2. Добавить ключ сервера в Deploy keys репозитория (публичная часть на сервере: `/etc/madelarme-deploy/id_ed25519.pub`, без права записи) и проверить цепочку целиком: пуш → строка `OK` в `/srv/server/projects/madelarme/deployments/releases.log` → новая сборка на сайте. Пока ключа нет, сборку ветки `deploy` доставлять на сервер вручную, как при первой установке: `git bundle` ветки `deploy` с офисного компьютера, на сервере `git fetch` из него в `/var/lib/madelarme-deploy/repo.git` и запуск скрипта выкладки с `NOFETCH=1` (пояснение в `deploy/office/madelarme-deploy.sh`).
3. Отложено: облегчить бандл через LazyMotion, поставить gitleaks и прогнать перед сдачей, получить от Марии ответы на открытые вопросы (раздел 16 плана) и занятые даты.
