Универсальный паттерн прямого файла: https://www.pexels.com/download/video/{ID}/?w=1920&h=1080 (для вертикальных ?w=1080&h=1920, лёгкая версия ?w=720&h=1280) — это 302-редирект на CDN videos.pexels.com/video-files/... — проверено curl'ом, работает без API-ключа; итоговые CDN-ссылки я привёл ниже. Файлы новых ID (>~25 млн) — fragmented MP4 (moof/mdat), обычный <video> их играет нормально. MIXKIT (Mixkit Stock Video Free License, https://mixkit.co/license/ — бесплатно коммерчески, без атрибуции): паттерн https://assets.mixkit.co/videos/{ID}/{ID}-1080.mp4 или -720.mp4 (у части клипов есть только -720, 1080 отдаёт 403); превью https://assets.mixkit.co/videos/{ID}/{ID}-thumb-720-0.jpg; 1080-файлы тяжёлые (30–100 МБ, высокий битрейт) — для веба брать -720 (3–5 МБ). COVERR (Coverr License, https://coverr.co/license — бесплатно коммерчески, атрибуция опциональна, единые условия для free/Coverr+): паттерн https://cdn.coverr.co/videos/coverr-{slug}/1080p.mp4 (также 720p.mp4, 360p.mp4); внимание: в выдаче Coverr много AI-generated роликов и «temp»-файлов — брать только классические слуги. - Hero главной: 3–4 клипа в ротации, все перекодировать в 1080p H.264 ~3 Мбит/с + WebM, ≤6 МБ каждый, без звука, poster-кадр из стила.
