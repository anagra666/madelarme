01

Коротко

  • Идея: сайт устроен как титры фильма — гигантская типографика, работы и форматы как строки индекса, видео появляется в ответ на действие и заливает экран. Плюс личный голос Маши: «Привет, я Маша», статус «сейчас: монтирую…», локации Алматы.
  • Визуально: тёплый чёрный + бумажный крем + один сигнальный цвет. Один сверхузкий дисплейный шрифт капсом, гротеск для текста, моно для «служебных» подписей (таймкоды, форматы, счётчики).
  • Главная: шоурил → индекс работ → Reels → три кейса подробно → форматы → Маша → цены → «Давай снимать».
  • Кейсы: каждая работа — «титровая карточка»: клиент, формат, задача, что снято, что получили (с хронометражами), сроки, кредиты. Такого нет ни у одного продакшена из выборки.
  • Мобилка — не адаптив, а отдельный сценарий: вертикальное видео в hero, все ленты — нативный свайп, sticky-полоса «Написать в WhatsApp», ≤1 играющего видео на экране.
  • Страницы: главная, работы, кейс, форматы (+ страница каждого формата), цены, Маша, Reels, контакты, шоурил, 404, политика.
  • Стек: Next.js 15 + Tailwind v4 + Motion; контент в JSON по схеме будущей админки (Payload CMS). Лупы — self-hosted mp4, полные фильмы — Bunny Stream / Kinescope.
  • Дальше: утверждаем план → собираю рабочий прототип на демо-контенте (главная + кейс + мобилка) → остальные страницы → показ Марии → реальный контент → админка.

Почему не работает

  • Первый экран видеографа — без видео: серое стоковое фото (сейчас даже оно не грузится) и serif-заголовок как у тысяч шаблонов «dark luxury».
  • Портфолио: 2 работы, обе с битыми превью (у одной thumbnail — путь к файлу на рабочем столе Марии). Нет описаний, нет отдельных страниц — нельзя дать ссылку на работу.
  • Семь равнозначных пунктов меню на одностраничнике; на телефоне три языковые кнопки толкаются с бургером.
  • Весь контент — seed-заглушки: 5 выдуманных отзывов (в одном оператора зовут «Артём»), календарь занятости за июнь, тарифы «в камерах и часах», одинаковые для свадьбы и рекламы.
  • Две формы с обязательным email и без единой кнопки WhatsApp — при том что аудитория мобильная.

Техническое

  • Next.js 15 + Tailwind v4 + Prisma, есть /admin — но HTTPS отсутствует (порт 443 закрыт), canonical и og:url ведут на IP, sitemap — на localhost. Для поисковиков сайт сломан; превью ссылки в WhatsApp/Instagram не собирается.
  • Публичные /api/settings и /api/portfolio открыты без авторизации.
  • RU/EN/KZ переключаются в JS без смены URL; казахская версия с опечаткой «кинematикалық».

Что повторяется у лучших

  • Монохром + ровно один агрессивный акцент (IL CAPO #D60001, SOMA #FF5625, Bouchard #fe443a).
  • Один дисплейный шрифт экстремальной ширины капсом (Druk Wide, Thunder, Sofia Sans Extra Condensed у DONPROD) + моно для метаданных.
  • Full-bleed беззвучный шоурил на первом экране, self-hosted mp4 или Vimeo/Mux/Bunny; никаких YouTube-iframe.
  • Список работ вместо сетки, видео по hover/скроллу; переключатель список/сетка (Remy Shoots, Palomino).
  • Категории = форматы съёмки, вынесенные в навигацию (Smuggler, Chris Macari: Films / Commercials / Music videos / Interview).
  • Кейс как «карточка фильма»: мета-поля + видео + credits + prev/next (Palomino, Tobi Films, Jeremie Bouchard).
  • Хедер прячется при скролле вниз; меню — полноэкранный оверлей; марки-строки клиентов.

Чего сознательно не делаем

  • Экран «enter with sound» и прелоадер 00→100: лишний тап на телефоне, съедает первый экран при переходе из Instagram.
  • Пять wow-эффектов на странице: у сайтов с одним приёмом оценка usability на Awwwards выше (7.9 против 7.0).
  • Горизонтальный wheel-скролл как основная навигация — конфликтует со свайпом «назад» на iOS.
  • Текст, физически разбитый на буквы в HTML (IL CAPO) — ломает поиск, копирование, скринридеры и SEO.
  • Кейсы как посты блога с датой публикации и «Newer / Older».
  • Заглушки в проде («This is some text inside of a div block») — все демо-данные помечаются флагом и скрываются одной кнопкой перед запуском.
04

Концепт: «Титры»

Сайт — это титры к её фильмам. Всё, что не видео, набрано как титры: гигантские строки-заголовки, моно-подписи с таймкодами и форматами, счётчики. Видео не лежит в карточках — оно появляется в ответ на действие и занимает весь экран. И поверх этого — голос Маши от первого лица, потому что клиент покупает человека, а не студию.

Как выбирали

Проработаны три направления: A «Кинотеатр» (летербокс, таймкоды, сцены), B «Капслок» (брутальный типографический индекс, кислотный акцент), C «Личный бренд» (тёплый, от первого лица, Reels-фид). Три независимые оценки — глазами Марии, жюри Awwwards и инженера. Ни одно направление не победило в чистом виде, все три оценки сошлись на гибриде.

Из B — каркас

Типографический индекс работ и форматов, секции-«перевёртыши» чёрный → бумага, прайс как титры с точками-лидерами, дисциплина: 5 цветов, radius 0, один движущийся эффект на секцию, счётчики «Свадьбы (12)».

Из A — кино-детали

Титровая карточка кейса, накамерный OSD в hero (REC ●, таймкод, «4K · 24 FPS»), жёсткие склейки вместо fade при смене видео, плеер-оверлей «сеанс», 404 с обратным отсчётом.

Из C — человек и конверсия

«Привет, я Маша», статус-строка из админки, цветной портрет с камерой, названия коллекций УТРО / ВЕСЬ ДЕНЬ / ТОЙ, Reels как в Instagram, sticky WhatsApp с предзаполнением по странице, форма без email.

Меняется одним токеном, вся система остаётся. Видео — единственный «цветной» объект: постеры по умолчанию приглушены, цвет приходит при hover / в активной строке.

Проверено по файлам Google Fonts: Sofia Sans Extra Condensed, Unbounded и JetBrains Mono не содержат казахских букв Ә Ғ Қ Ң Ө Ұ Ү Һ. Oswald, Inter Tight, Onest и Roboto Mono — содержат. Поэтому дисплей для RU/EN — Sofia Sans EC (самый «дерзкий»), для страниц на казахском — Oswald; текст и моно выбраны сразу с полной кириллицей. Решение по языкам на запуске — вопрос №2 в конце.

Словарь движения

  • Выезд из-под маски — все заголовки появляются построчно (Vertical Cut Reveal), stagger 0.04 с.
  • Склейка, не fade — смена видео за индексом и цитат в отзывах: жёсткий cut + один кадр белой засветки.
  • Roll-hover букв в строках индекса; номер «прокручивается» как счётчик плёнки.
  • Марки — бегущие строки форматов и клиентов, пауза по hover, замедление по touch.
  • Занавес — один жест clip-path для открытия меню, плеера и hero: полосы смыкаются и раскрываются.
  • Курсор «▶ смотреть» и магнит на кнопках — только при pointer: fine; на тач — tap-feedback scale(.98).
  • Одна кривая на весь сайт cubic-bezier(.16,1,.3,1), 0.5–0.9 с. prefers-reduced-motion: постеры вместо автоплея, reveal → мгновенно.

Пять фирменных моментов

  • Вордмарк-экран. MADELARME во всю ширину, внутри букв играет шоурил; при первом скролле видео выходит из букв на весь экран, вордмарк уезжает в шапку (десктоп). На телефоне — вертикальный шоурил с вордмарком поверх.
  • Индекс работ. Строка = № · НАЗВАНИЕ · клиент · формат · год · хронометраж. Hover — строка загорается сигналом, за списком на весь экран проявляется тизер этой работы. На телефоне — мини-тизер 9:16 прямо в строке.
  • Титровая карточка. Кейс читается за 20 секунд: задача → что снято → что получили с хронометражами → кредиты. Ни у Iconoclast, ни у Somesuch такого нет.
  • Reels как в Instagram. Лента 9:16 с полукадром следующей; тап — story-режим на весь экран, звук по тапу, свайп вниз закрывает.
  • Пометки Маши. Статус «Алматы · 18:42 · сезон 2027 открыт · сейчас: монтирую N&N», локации, подпись madelarme сигнальным цветом — редактируется в админке.

Кейс: как описана каждая работа

Поля (сейчас JSON, потом коллекция Case в админке)

  • Название как у фильма (≤14 символов капсом для мобильной строки: «ТАУ-ТОЙ», «ГОРОД НЕ СПИТ») + логлайн — одна дерзкая фраза.
  • Клиент (пара или бренд), формат (ссылка на таксономию), настроение (дерзкие / нежные / документальные), город · площадки · дата.
  • Медиа: тизер-луп 16:9 и 9:16 (mp4 ≤4/≤3 МБ), постеры 16:9 / 9:16 / 4:5 (WebP), полный фильм (Bunny Stream / Kinescope / Vimeo id + хронометраж), Reels[], стиллы[] (6–12), «цвет до/после» (опц.).
  • Съёмка: дни, часы, операторы, дрон, техника. Пост: монтаж, цвет, звук, сроки сдачи.
  • Задача (2 предложения) · Как снимала (1 абзац) · Результат (цифры + факт: «тизер показан на банкете в 22:40»).
  • Что получили[] — название · хронометраж · aspect («Тизер · 0:60 · 16:9 + 9:16», «SDE · 1:30», «5 Reels · 9:16»).
  • Титры[] — роль · имя (второй оператор, цвет, звук, фото, организатор, площадка, музыка/лицензия). Маша всегда первой строкой.
  • Цитата клиента (опц.), featured_in (опц.), is_placeholder, is_published, порядок, SEO (og-image из кадра тизера, JSON-LD VideoObject).

Раскладка страницы сверху вниз

  1. Экран-тизер 100svh: беззвучный луп, моно-строка [ 01 / 24 ] · [ формат ] · [ город · год ], название дисплеем 16vw, логлайн, кнопка «▶ Смотреть фильм 08:12» → плеер-оверлей (закрыть / пауза / звук / fullscreen / свой таймлайн), страница не меняется.
  2. Титровая карточка — 5–6 ячеек: клиент · формат RU+EN · где/когда · съёмка · сдача. На телефоне — ledger в две колонки.
  3. Тело: слева sticky «Что получили» + «Съёмка» + «Пост» ledger-ом; справа главы [ 01 ] Задача · [ 02 ] Как снимала · [ 03 ] Результат. На телефоне — стопкой.
  4. Reels из кейса — ряд 9:16 (на телефоне scroll-snap).
  5. Кадры — masonry 6–12 стиллов с лайтбоксом; опционально «цвет до / после».
  6. Цитата клиента дисплеем 4vw с подписью и «смотреть их Reels →».
  7. Титры — две колонки моно с точками-лидерами; ниже теги настроения и локации как ссылки-фильтры.
  8. Следующий кейс — гигантская строка «СЛЕДУЮЩАЯ → ГОРОД НЕ СПИТ», hover — тизер за строкой; «← предыдущая» мельче. Sticky-CTA «Хочу как у Айгерим & Данияра».

Правила: страница начинается с видео, не с текста; весь текст остаётся в DOM целым (анимация букв — через JS с aria-label); у всех медиа задан aspect-ratio (CLS 0); плашка «ДЕМО-КОНТЕНТ · клиент вымышлен» при is_placeholder, такие кейсы не попадают в sitemap.

Мобильная стратегия

Основной вход — ссылка из био Instagram, открытая во встроенном браузере Instagram или Safari на iPhone и Chrome на Android. Проектируем от 390×844 с проверкой на 360 и 430.

  1. Hero = 100svh (не vh), вертикальный mp4 ≤3 МБ, постер ≤40 КБ с fetchpriority=high; H1 и CTA отрендерены сервером, без opacity:0 до гидратации.
  2. Автоплей честно: muted playsinline, play() из JS с catch → постер + ▶; повторный play через 250 мс для Instagram in-app; при saveData / 2g видео не грузится вообще.
  3. Все горизонтальные ленты — нативный overflow-x + scroll-snap, следующая карточка видна полукадром, ≤8 элементов, отступ 24px слева (не конфликтует с системным «назад»). Никаких пинов и GSAP на тач.
  4. Играет ≤1 видео одновременно (IntersectionObserver 0.6, пауза при уходе и в фоне), остальные preload=none + постер.
  5. Hover не существует: у каждого hover-приёма есть tap-эквивалент: раскрытие строки → страница, превью за курсором → мини-тизер в строке, курсор → выключен.
  1. Sticky-полоса CTA 56px + safe-area: «Обсудить съёмку · WhatsApp» + Telegram + Instagram. Появляется после 60% hero, прячется при скролле вниз, показывается вверх; скрыта, пока открыт плеер / story-режим / видна форма; выключена на /contact и /reels.
  2. Предзаполнение текста WhatsApp по странице: главная «Здравствуйте, Мария! Хочу обсудить съёмку», кейс «Хочу как у [название]», формат «Хочу обсудить [формат]», прайс «Проверить дату на коллекцию [название]».
  3. Tap-цели ≥44px, CTA 56px, названия кейсов ≤14 символов с авто-подгонкой кегля до 9vw для длинных и казахских названий.
  4. Шрифты self-host через next/font, subsets latin + cyrillic(+ext), preload только дисплейного для H1; ≤4 файла woff2.
  5. Ручной тест перед показом: iPhone в Low Power Mode, первое открытие из Instagram-био, Android Chrome с Lite mode, WhatsApp in-app; Lighthouse Mobile 4G.

Технологии

Фронт

  • Next.js 15 (App Router, RSC, ISR) + TypeScript — тот же стек, что на текущем сайте, переезд без смены хостинга.
  • Tailwind v4 с токенами темы (5 цветов, radius 0, шкала кеглей).
  • Motion (motion/react) — единственный движок анимаций на мобильной сборке; GSAP — только dynamic import для hero-pin на десктопе; Lenis — только при pointer: fine.
  • Шрифты через next/font, Playwright-скриншоты 390 / 768 / 1440, Lighthouse CI на 4G.

Видео и хостинг

  • Лупы и превью: self-hosted mp4 720p (≤4 / ≤3 МБ) + WebP-постеры на Bunny Storage + CDN (~$1–5/мес).
  • Полные фильмы и шоурил: Bunny Stream (HLS + mp4-fallback, свой плеер, без чужого лого) или Kinescope (СНГ, оплата из KZ) — решить по способу оплаты. YouTube — только внешний канал.
  • Транскодирование: FFmpeg-скрипты сейчас, очередь на сервере — в админке.
  • Хостинг: текущий VPS (Ubuntu / nginx) или Hetzner; Let’s Encrypt, 301 http→https, никаких Cloudflare-челленджей (ломают превью в мессенджерах).

Контент-модель (контракт для админки)

  • Коллекции: Case · Reel · Format · PriceCollection · Extra · FAQ · Testimonial · Client · Showreel · Settings (манифест, статус-строка, сезон, контакты, тексты предзаполнения, тумблеры).
  • Сейчас — /content/*.json ровно по этой схеме; потом миграция скриптом в Payload CMS 3 в том же репозитории (Postgres на VPS, медиа в Bunny через S3-адаптер, загрузка с телефона, роли admin/editor, превью черновиков).
  • Лиды: server action → Telegram-бот + email + Google Sheet. Аналитика: Яндекс.Метрика + GA4 с событиями на wa.me/t.me.
  • SEO: canonical, og:image на каждую страницу, JSON-LD Person / LocalBusiness / VideoObject / Service, sitemap с реального домена; локали /kk и /en через next-intl — позже.

Риски и юридика

  • Дизайн на стоках. После подстановки реальных кадров композиция может «поплыть» (светлое платье под текстом, длинные названия). Лечится: лимит длины названий, скрим под текстом, проверка на самом светлом кадре, утверждение на минимум 4 реальных кейсах.
  • Права на кадры. Свадебные фильмы — согласие пар (пункт в договоре «публикация в портфолио»); OYU Fest и Red Bull — права могут быть у заказчика. Музыка в шоуриле со звуком — только лицензированный трек (Artlist / Epidemic / Uppbeat с web-лицензией).
  • Персональные данные. Форма собирает имя и телефон — нужна политика конфиденциальности и строка согласия по закону РК; формы только по HTTPS.
  • Шрифты и казахский. Sofia Sans EC / Unbounded / JetBrains Mono без казахских глифов — решено заменой на Oswald / Roboto Mono для KZ-страниц; не обещать «/kk потом» без этого.
  • Производительность. Главная с 15–20 видео на 4G — держим лимиты (≤8 видео на экран прокрутки, ≤1 играющего на тач), тестируем на среднем Android.
  • Вымышленные бренды. Brew Coffee / Neon Dreams / TechSummit из старого seed могут совпасть с реальными — переименовываем в заведомо вымышленные и помечаем «демо».
  • Аналитики нет. Тезис «основной трафик с телефонов» не измерен — ставим Метрику + GA4 на текущий сайт уже сейчас, через месяц будет baseline.
